An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI — every official name, description and grade, a guide in our own words with its sources cited beside it, a roadmap to the Platinum (Vice Got a Price!), the one missable trophy flagged (Positive Mental Attitude — Lucia's Chapter 1 balcony meditation), and a checklist with progress saved in the browser, filters by kind (story, missable, collectibles, activities, online), a spoiler setting that hides story trophies until earned, and export/import. The app is static files under `app/` and works with the network off.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
