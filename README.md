A complete, offline GTA VI trophy guide and tracker for all 55 PS5 trophies — a roadmap, a searchable checklist with progress saved in your browser, and export/import of your progress. Open `app/index.html` to use it; no server, no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
